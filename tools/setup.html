⚙️ Configurar o app da família

Esta página roda só no seu navegador: o token nunca sai daqui, a não ser cifrado. Use-a para gerar o config.js e o link de convite.

1. Token do repositório de dados

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → só o repositório de dados (ex.: financas-data, privado).
  3. Permissions → Repository → Contents: Read and write. Validade: até 1 ano (anote para trocar antes de vencer).

2. Código da família

É a "senha da família" para usar o app num aparelho novo. Como o token cifrado fica público no site, use uma frase longa (4 palavras ou mais), ex.: bolo-de-fuba-da-vovo-1987.

3. Publicar

Substitua o arquivo config.js na raiz do repositório do app por este conteúdo e faça commit/push:
